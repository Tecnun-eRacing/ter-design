# Introduccion
Sitio centralizado con todo el diseño general, lista de cosas que hacer y documentacion general de la electronica del coche. Tambien estan aqui todas las librerias de hardware y software que se usan para el desarrollo de las placas.

Todo el "codigo" de esto se encuentra aqui, en este [repositorio](https://github.com/Tecnun-eRacing/ter-design) esta tanto el texto como todas las librerias de las que hablo.
Para modificar el texto de alguna pagina o añadir una nueva, clonar el repo y en la carpeta book/src cambiar el texto de la pagina selecionada. Al hacer push se actualizara solo.
